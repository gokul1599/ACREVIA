### STAGE 04 — FASTAPI BACKEND, DATABASE & TENANT ISOLATION

#### Task: `TASK-S04-01`
- **Stage:** Stage 04
- **Exact Stage Heading:** STAGE 04 — FASTAPI BACKEND, DATABASE & TENANT ISOLATION
- **Feature:** Alembic Migration DDL Generation & Rollback Reversibility
- **Finding:** Migration `f4894a11c87d` applies schema changes via `Base.metadata.create_all(bind=bind)`. While this creates all 132 ORM tables reliably on a fresh database, it does not generate granular DDL statements (`op.create_table`, `op.add_column`, `op.drop_table`), leaving `downgrade()` as an empty function and preventing safe reversible rollbacks.
- **Evidence:** `backend/alembic/versions/f4894a11c87d_initial_schema_consolidation.py` lines 24–35
- **Severity:** Medium
- **Dependency:** None
- **Recommended Action:** Discontinue `create_all()` in Alembic migrations; generate an autogenerated DDL migration baseline using `alembic revision --autogenerate` for post-v1.0 schema changes.
- **Acceptance Criteria:** New migrations define explicit `op.create_table` and `op.add_column` calls, and `alembic downgrade -1` successfully rolls back the latest revision.
- **Verification Method:** Execute `alembic upgrade head` followed by `alembic downgrade -1` in a staging PostgreSQL container.
- **Priority:** **P2**

### STAGE 06 — FARMER PWA, OFFLINE-FIRST UX, VOICE & SYNCHRONIZATION

#### Task: `TASK-S06-01`
- **Stage:** Stage 06
- **Exact Stage Heading:** STAGE 06 — FARMER PWA, OFFLINE-FIRST UX, VOICE & SYNCHRONIZATION
- **Feature:** Client-Side Offline Storage Migration to IndexedDB
- **Finding:** Client-side queue in `frontend/lib/offline/queue.ts` stores pending mutations and scouted observations in browser `localStorage`. Browsers restrict `localStorage` to approximately 5MB. Storing high-resolution base64 leaf photographs while offline will cause an unhandled `QuotaExceededError`.
- **Evidence:** `frontend/lib/offline/queue.ts` lines 28–64 (`window.localStorage.getItem(...)`)
- **Severity:** High
- **Dependency:** None
- **Recommended Action:** Replace `localStorage` with an `idb` or `Dexie.js` wrapper backed by native browser `IndexedDB`, with asynchronous chunking and binary Blob storage for offline leaf images.
- **Acceptance Criteria:** PWA client can store at least 50 full-resolution offline observations ($> 50\text{ MB}$ total) without throwing storage quota exceptions.
- **Verification Method:** Automated Playwright/Jest offline test simulating 50 consecutive image captures in offline mode, asserting queue persistence and successful re-sync upon network reconnection.
- **Priority:** **P1**
