# ACREVIA — SENSOR CALIBRATION AND DATA QUALITY (PILLAR C: ACREVIA SENSE)
## Validation Rules, Anomaly Detection & Calibration Life Cycle Management

---

## 1. Overview
Field sensors deployed in agricultural environments face harsh soil mineralization, bio-fouling, solar degradation, and intermittent power supply. Acrevia Sense enforces automated quality control (QC) checks on every incoming packet before telemetry is accepted into downstream agronomic models.

---

## 2. Telemetry Physical Boundary Bounds

Any reading outside biophysical limits is immediately flagged as `OUT_OF_BOUNDS`:

| Metric | Valid Range | Physical Failure Indication |
|---|---|---|
| **Soil Moisture (VWC)** | $0.0\% \le \theta \le 100.0\%$ | Sub-zero indicates ADC grounding fault; $> 100\%$ indicates probe saturation or short circuit |
| **Soil Temperature** | $-5.0^\circ\text{C} \le T_{\text{soil}} \le 65.0^\circ\text{C}$ | $>65^\circ\text{C}$ indicates dry soil probe exposed to direct scorching sunlight |
| **Ambient Temperature** | $-10.0^\circ\text{C} \le T_{\text{amb}} \le 60.0^\circ\text{C}$ | Values $>60^\circ\text{C}$ in Telangana indicate casing sensor cook / failure |
| **Relative Humidity** | $0.0\% \le RH \le 100.0\%$ | Negative or $>100\%$ values indicate capacitive hygrometer drift |
| **Leaf Wetness** | $0.0\% \le LW \le 100.0\%$ | Grid sensor corrosion |
| **Battery Level** | $0.0\% \le Bat \le 100.0\%$ | Voltage divider drift |

## 3. Automated Anomaly Detection Rules

### 3.1 Stuck Sensor Detection (`SUSPECT_STUCK`)
- **Rule:** If a sensor reports identical floating point values ($\Delta \le 0.001$) across 6 consecutive hourly readings, it is flagged as `SUSPECT_STUCK`.
- **Reason:** Real ambient environment undergoes diurnal oscillation; identical values indicate frozen firmware or ADC register latchup.

### 3.2 Physical Spike Detection (`SUSPECT_SPIKE`)
- **Rule:** If soil moisture jumps by more than $30\%$ within a 15-minute interval without corresponding rainfall logged by the weather station, or if temperature fluctuates by $>15^\circ\text{C}$ within 15 minutes.

## 4. Calibration Tracking & Confidence Penalties

Every sensor device maintains a calibration ledger:
- `last_calibrated_at`: Timestamp of physical laboratory or field calibration.
- `calibration_valid_until`: Expiration timestamp (standard 180 days for capacitive soil probes, 365 days for temperature/RH).
- `calibration_offset` and `calibration_slope`: Linear calibration coefficients applied to raw analog readings.

### Calibration Penalty Policy:
- If a sensor's calibration validity has expired (`current_time > calibration_valid_until`), its quality status is set to `UNCALIBRATED`.
- All confidence scores generated by downstream risk models utilizing this sensor's data are penalized by **25%**, and a prominent advisory note is appended:
  > *"Warning: Field sensor calibration expired on [Date]. Readings may reflect drift. Recalibration recommended."*
